# Shanmukha Manidhar — Personal Engineering Portfolio & Digital Workspace

A distinctive, premium, and authentic personal developer portfolio built for **Shanmukha Manidhar**, Computer Science & Engineering student and aspiring Software / AI & ML Engineer.

Designed around the philosophy: **"An engineer's personal digital workspace."**

---

## ✦ Core Design Principles (Anti-Template Rationale)

1. **No AI Clichés or Boilerplate Aesthetics**:
   - Zero generic purple-blue gradients
   - No huge glowing blurry blobs
   - No generic rounded cards or glassmorphism
   - No fake 3D developer characters or stock avatars
   - No "Welcome to my portfolio" hero section
   - No meaningless progress bars or boring skill logo grids

2. **Editorial Architectural Visual Language**:
   - Strong typographic hierarchy pairing **Plus Jakarta Sans** (headings), **Inter** (body), and **JetBrains Mono** (technical specifications, code, and telemetry).
   - Near-black deep background (`#090a0c`), off-white typography, hairline blueprint ruling lines (`#23252d`), and a single, disciplined accent: **International Signal Orange (`#ff5500`)**.
   - Fully designed, authentic **Light Mode** inspired by Swiss architectural monographs (warm alabaster archival paper `#f8f7f4`, ink typography, and stone borders) — not a crude inversion.
   - Built to look stunning even with all animations disabled (`prefers-reduced-motion`).

3. **Engineering Credibility & Storytelling**:
   - Focus on concrete systems software, algorithms, data structures, and real technical challenges.
   - No exaggerated statistics, fake clients, or fabricated testimonials.
   - Comprehensive **8-point case studies** for every project.

## ✦ Technical Features

- **Interactive System Canvas**: Real-time interactive node canvas featuring 3 modes: *Topological Lattice Graph*, *Multispectral Raster Matrix*, and *Register Buffer Inspector*.
- **Full-Screen 8-Point Case Study Modal**: Deep-dive technical view for all projects with interactive architecture pipeline steps, copyable native code snippets, bottleneck resolution logs, and keyboard shortcuts (`ESC`, Arrow keys).
- **Command Palette (`Ctrl+K` or `⌘K`)**: Instant keyboard navigation to jump between sections, launch case studies, toggle themes, or copy contact information.
- **Purpose-Driven Engineering Stack**: Skills organized by engineering discipline (`LANGUAGES`, `WEB & CLIENT ARCHITECTURE`, `DATABASE & STORAGE`, `AI & MACHINE LEARNING`, `TOOLS & ENVIRONMENT`) with an interactive Engineering Dossier inspector.
- **Engineering Flight Log & Timeline**: Chronological log of academic coursework, project milestones, industry job simulations, and technical hackathons with verifiable technical takeaways.
- **Live Code Craftsmanship & Repo Inspector**: In-browser source code viewer with line numbers and architectural rationale for Python, C, and MongoDB.
- **Workspace Telemetry Drawer**: Floating bottom telemetry bar showing live scroll percentage, active viewport section, DOM element count, and quick controls.
- **Tactile Web Audio Feedback**: Optional, subtle synthesized mechanical clicks on interaction.

## ✦ Development & Deployment

### Quick Start
```bash
# 1. Navigate to the project directory
cd portfolio

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build locally
npm run preview
```

### Production Deployment
The build output is located in `portfolio/dist`. It is fully static and ready for instant deployment to **Vercel**, **Netlify**, **Cloudflare Pages**, or **GitHub Pages**.
